# Curso de Análisis de Algoritmos

## Informes de Laboratorio — Ejercicios en Clase — Análisis de Algoritmos

Repositorio destinado al desarrollo y documentación de los informes de laboratorio evaluativos del curso de Análisis de Algoritmos.

## Propósito de las carpetas

Las carpetas del repositorio se organizan de la siguiente manera:

* `ejercicios-clase/`: contiene los ejercicios y prácticas desarrollados durante las clases.

* `laboratorio-1/` — [Laboratorio 1](laboratorios/lab1-fundamentos-complejidad-recurrencias): contiene los archivos correspondientes al primer informe de laboratorio.

* `laboratorio-2/` — [Laboratorio 2](laboratorios/lab2-divide-y-vencer): contiene los archivos correspondientes al segundo informe de laboratorio.

* `laboratorio-3/` — [Laboratorio 3](laboratorios/lab3-estructuras-datos): contiene los archivos correspondientes al tercer informe de laboratorio.

* `laboratorio-4/`: contiene los archivos correspondientes al cuarto informe de laboratorio.

* `laboratorio-5/`: contiene los archivos correspondientes al quinto informe de laboratorio.

* `benchmarks/`: contiene las pruebas de rendimiento utilizadas para medir y comparar la eficiencia de los algoritmos implementados.
